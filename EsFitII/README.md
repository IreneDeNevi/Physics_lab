# EsFitII

## Overview
Second set of fit exercises focused on exponential models, binned likelihood fits, and ROOT/Python cross-checks.

## Main Files
- `fitexp.C`, `fitexp_ROOT.C`: exponential fit scripts.
- `fitexpbin.py`, `fitexpbin_ROOT.py`, `fitexpbin_ext.py`, `fitexpbinext_ROOT.py`: binned fit variants.
- `test.C`: test script.
- `exp.dat`, `pendolo.dat`: input data.

## Run
```bash
python fitexpbin.py
```

## Notes
Different files reflect alternative implementations explored during the same lab sessions.
