# Esercitazione 4

## Overview
MATLAB/Octave implementations of finite-difference and PDE schemes used during Laboratory 3.

## Main Files
- `CN.m`: Crank-Nicolson style scheme.
- `HeatScheme.m`, `HeatSchemeAsym.m`: heat equation solvers.
- `Laplace.m`, `Poisson.m`: elliptic PDE examples.
- `Corda.m`: wave/string-related exercise.

## Run
Open the scripts in MATLAB or GNU Octave and execute them individually.

## Notes
Parameters are generally embedded in each script and can be modified to explore stability and convergence.
