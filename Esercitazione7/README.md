# Esercitazione 7

## Overview
Statistical analysis exercises (including counting experiments and simple signal/background models) using Python + ROOT.

## Main Files
- `compito.py`: event counting, p-value scan, and model fit.
- `Millikan.py`, `parte1.py`, `parte2.py`: additional analysis exercises.
- `dati_highstat.dat`, `dati_lowstat.dat`, `Millikan.dat`: datasets.

## Run
```bash
python compito.py
```

## Notes
Backup files with `~` suffix are preserved as historical snapshots from the course work.
