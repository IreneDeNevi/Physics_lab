# Esercitazione 1

## Overview
This folder contains introductory C++ object-oriented exercises from Laboratory 3 (BSc Physics), focused on vectors, particles, and material points.

## Main Files
- `Vettore.h`, `Vettore.cpp`: 3D vector class and operators.
- `Particella.h`, `Elettrone.h`: particle abstractions.
- `PuntoMateriale.h`, `PuntoMateriale.cpp`: material point with fields.
- `main.cpp`: vector operations and file-based sorting example.
- `MainPM.cpp`: checks and demonstrations on `PuntoMateriale`.
- `Makefile`: build entry point.

## Build And Run
```bash
make
./MainPM
```

To test `main.cpp`, compile it manually or add a specific target to the Makefile.

## Notes
Files ending with `~` are backup/editor temporary copies and can be ignored in normal workflows.
