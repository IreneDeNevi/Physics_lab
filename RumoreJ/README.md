# RumoreJ

## Overview
Johnson noise analysis workspace with multiple resistor datasets and ROOT/C++ processing scripts.

## Main Files
- many `*.txt` and `*.pdf` files: measured spectra for different resistances.
- `dati.dat`, `dati_S.dat`: aggregate datasets.
- `esercizio.cpp`, `tmp.cpp`: analysis scripts.
- `esercizio`: compiled artifact.

## Run
Compile and run `esercizio.cpp` with ROOT libraries.

## Notes
The folder includes several temporary or backup files (`~` suffix) that document incremental lab work.
