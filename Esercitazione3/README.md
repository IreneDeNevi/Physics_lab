# Esercitazione 3

## Overview
Python numerical methods exercises, including integration schemes and a Numerov-style approach for quantum-like differential equations.

## Main Files
- `compito.py`: Numerov-based matching and energy search workflow.
- `num_skeleton.py`: skeleton/template for numerical work.
- `verlet_example.py`: example of Verlet integration.

## Run
```bash
python compito.py
```

## Notes
Scripts are intended as educational notebooks-in-code from Laboratory 3 and may prioritize clarity over packaging.
