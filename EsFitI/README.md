# EsFitI

## Overview
First set of fit exercises from Laboratory 3, mostly linear regression and Minuit-based estimation.

## Main Files
- `fitlin.py`, `fitlin.C`: linear fit implementations.
- `fitlin_iminuit.py`, `fitlin_iminuit_par.py`: iminuit-based variants.
- `skel3.cpp`: C++ skeleton.
- `pendolo.dat`, `perno1.dat`, `perno2.dat`: datasets.

## Run
```bash
python fitlin.py
```

## Notes
Both ROOT-native and Python-based fitting approaches are included for comparison.
