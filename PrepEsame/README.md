# PrepEsame

## Overview
Exam-preparation collection with mixed C++, Python, and MATLAB exercises, plus datasets and archived exam materials.

## Main Structure
- `es1.cpp`, `es4.cpp`, `es5.cpp`, `es8.cpp`, `es9.cpp`, `es17.cpp`, `es18.cpp`: C++ problems.
- `es3.py`, `es7.py`, `es12.py`, `es13.py`, `es14.py`: Python problems.
- `es6.m`, `es10.m`: MATLAB scripts.
- `myTF1.cpp`, `MYTF1.h`: custom ROOT function class.
- `Esami/`, `esempio esame a distanza/`: archived exam material.

## Notes
This folder is broad by design and useful as a revision bank rather than a single runnable project.
