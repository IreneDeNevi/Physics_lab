# Esercitazione 5

## Overview
Data analysis and simulation scripts in Python and C++, including ROOT-based fitting workflows and Gaussian random generation.

## Main Files
- `compito.py`: prism-related fit workflow with uncertainty propagation.
- `Gauss.py`: Gaussian random generation with ROOT histograms.
- `PrismScheme.cpp`, `PrismScheme.py`, `PrismScheme2.py`, `PrismScheme3.py`: prism scheme variants.
- `PrismScheme`: compiled executable/artifact.

## Run
```bash
python compito.py
python Gauss.py
```

## Notes
Scripts were written during Laboratory 3 and are now normalized to standard ASCII operators and Python syntax.
